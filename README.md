# Pete Thinkful Portfolio

This project is a personal portfolio website for Pete Thinkful, an artist based in Denver, Colorado. The site showcases background information, selected artwork, and social links for contacting or following Pete.

The project was built as a capstone exercise to demonstrate proper HTML structure, semantic markup, and CSS styling.

## 📁 Project Structure

- `index.html` – Main HTML file containing the page structure  
- `style.css` – CSS file used to style the page  
- `images/` – Folder containing artwork and profile images  
- `README.md` – Project documentation  

---

## ✅ Features

- Semantic HTML using `header`, `nav`, `section`, `article`, and `footer`
- Navigation links to About, Portfolio, and Contact sections
- Centered headings, text, and images using CSS
- Clear heading hierarchy for accessibility and readability
- Circular profile image with custom border styling
- Responsive-friendly structure
- Deployed using GitHub Pages

## 🛠 Technologies Used

- HTML5

- GitHub Pages
